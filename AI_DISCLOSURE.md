## Scope

DSH WhaleConsole contains material created or revised with generative AI under human direction. This includes parts of the project planning, code drafts, interface text, documentation, original character concepts and illustrations, skin-thumbnail compositions, and application artwork.

Human contributors selected, edited, reviewed, tested, and integrated the published results. AI assistance does not imply that DeepSeek, DSH, an AI provider, or any other third party endorses or sponsors this project. No official DeepSeek or DSH logo or upstream brand asset is included.

## Responsibility

Project maintainers remain responsible for source review, functional behavior, security decisions, compatibility testing, licensing, attribution, and release approval. Generative output can contain mistakes or unintended similarities. Please report a concern through the repository issue or security-reporting process.

## Contributions

Contributors should disclose material AI assistance in a pull request when it affects code, documentation, design, or artwork. They must review generated material, remove secrets and personal data, verify that submitted assets do not intentionally reproduce third-party copyrighted characters or unlicensed works, and retain useful source or provenance information when practical.
