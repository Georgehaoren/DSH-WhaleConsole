- [x] 导出 `./package.json`，供 DSH 客户端发现插件。
- [x] 生成 lazy-CJS 客户端工厂。
- [x] Host 设置命名空间与浏览器设置卡片使用同一个键。
- [x] 仅使用增量插槽，不替换根节点或核心界面。
- [x] 针对 `0.1.1-rc.2` 验证真实 DSH profile 组合。

- [x] 启动器能够区分内部与外部服务进程。

- [x] 使用单一 `skinId` 同时控制配色与角色，不重复保存外观字段。
- [x] 包含原创美术及对应素材许可证。
- [x] 在源码仓库与插件压缩包中包含中英文 AI 辅助创作声明。
- [x] 包含中英文源码安装入口、Agent Skill 与详细操作规程。
